Long Description / 长描述

This project is designed for first-year Computer Science students to practice basic HTML tags. It includes interactive examples and a simple responsive layout.

本项目专为计算机科学专业大一学生设计，用于练习基础 HTML 标签。包含交互式示例和简单的响应式布局。
